## 概述

JavaFramework 的数据持久化层提供 KV 存储和文件操作能力，支持进程内和跨进程访问模式。KV 存储基于 JSON 文件实现，采用内存缓存 + 延迟刷盘策略，平衡性能与可靠性。文件操作通过 FileManager 单例统一管理，支持事务性读写和并发控制。

缓存系统（CachePool）提供泛型 LRU 缓存能力，基于双向链表和哈希表实现，适用于需要快速访问和自动淘汰的场景。所有持久化操作均通过 DispatcherQueue 异步执行，避免阻塞主线程。

## 核心机制

### KV 存储实现

**SimpleKV** (`com.cxuy.framework.io.kv.SimpleKV:22-347`) 是主要的 KV 存储实现：

**存储结构**：
- 内存层：`Map<String, String> kvMap`，使用 `Collections.synchronizedMap` 保证线程安全（`SimpleKV:30`）
- 文件层：JSON 格式存储到 `simple_kv/{name}.kv` 文件

**延迟刷盘策略** (`SimpleKV:323-332`):
```java
private void recordApply() {
    synchronized(writeLock) {
        writeCount++;
        applyChange = writeCount == MAX_WRITE_TO_DISK_COUNT; // 每10次写操作刷盘
    }
    if(applyChange) {
        apply(); // 触发异步刷盘
    }
}
```

**初始化同步** (`SimpleKV:334-346`):
```java
private boolean waitForInit() {
    synchronized(initLock) {
        while(!isInit.get()) {
            initLock.wait(); // 等待文件读取完成
        }
    }
    return true;
}
```

**生命周期集成**：实现 `LifecycleObserver`，在 `DID_DESTROY` 状态时强制刷盘（`SimpleKV:266-270`）

### 文件操作架构

**FileManager** (`com.cxuy.framework.io.file.FileManager:25-307`) 是单例文件管理器：

**事务性保证**：
- 每个文件路径对应一个 `FileExecutor` 实例（`FileManager:70-72`）
- `mutex()` 方法保证互斥访问（写操作）
- `share()` 方法允许多个读操作并发（`FileManager:118`）

**文件操作模式** (`FileManager:35-37`):
```java
public interface WriteFileCallback<T> {
    int MODE_WRITE = 0;    // 覆盖写入
    int MODE_APPEND = 1;   // 追加写入
}
```

**路径解析** (`FileManager:294-298`):
```java
private String resolvePath(String path) {
    return Paths.get(path).toAbsolutePath().normalize().toString();
}
```

### 缓存策略

**CachePool** (`com.cxuy.framework.util.CachePool:12-167`) 实现泛型 LRU 缓存：

**数据结构**：
- 双向链表（head 为哨兵节点）：维护访问顺序
- `HashMap<K, Node<K, M>> searchMap`：O(1) 查找
- `Queue<Node<K, M>> nodePool`：节点对象池，减少 GC

**核心操作** (`CachePool:41-61`):
```java
public void put(K key, M model) {
    worker.async(() -> {
        Node<K, M> node = searchMap.remove(key);
        node.model = model;
        remove(node);      // 从链表中移除
        insert(head, node); // 插入到头部（最近使用）
    });
}
```

**删除回调** (`CachePool:67-87`):
支持注册 `ItemHasDeleted` 监听器，在节点被移除时触发通知。

**异步执行**：所有操作提交到专用 DispatcherQueue（`CachePool:28`），保证线程安全。

## 约束与注意事项

1. **SimpleKV 刷盘阈值**：默认每 10 次写操作触发一次文件刷盘（`MAX_WRITE_TO_DISK_COUNT = 10`，`SimpleKV:25`）
2. **初始化阻塞**：首次读取时 `waitForInit()` 会阻塞等待文件加载完成，需确保文件存在或处理超时（`SimpleKV:334-346`）
3. **文件操作回调**：FileManager 的 read/write 方法接受回调，不支持直接返回值（`FileManager:108-126`）
4. **CachePool 异步特性**：put/get/remove 操作异步执行，回调中获取结果（`CachePool:89-103`）
5. **路径约定**：SimpleKV 存储路径为 `{rootDir}/simple_kv/{name}.kv`，KVMap 为 `{rootDir}/kv_map/{name}.kv`
6. **生命周期绑定**：SimpleKV 注册为 LifecycleObserver，Context 销毁时自动刷盘（`SimpleKV:48`）
7. **并发文件访问**：同一文件路径的多个操作通过 FileExecutor 串行化，不同文件可并发（`FileManager:70-72`）
