## 概述

JavaFramework 的并发模型基于协程（Coroutine）概念，通过 `DispatchQueue` 接口和 `DispatcherQueue` 实现提供任务调度能力。系统区分标准调度队列和 IO 调度队列，支持同步/异步执行、延迟任务和任务组管理。

核心设计采用生产者-消费者模式：任务提交到优先级队列，工作线程循环获取并执行。对于 IO 密集型任务，使用独立的线程池（`ThreadPoolExecutor`）避免阻塞事件循环。DispatchGroup 提供高级抽象，允许批量提交任务并在全部完成后触发回调。

## 核心机制

### 协程调度机制

**DispatchQueue 接口** (`com.cxuy.framework.coroutine.DispatchQueue:14-53`) 定义两种队列：
- `standard`: 标准调度队列（`DispatchQueue.standard`）
- `io`: IO 调度队列（`DispatchQueue.io`），启用协程线程池

**DispatcherQueue 实现** (`com.cxuy.framework.coroutine.queue.DispatcherQueue:22-404`):

1. **任务队列**：使用 `PriorityQueue<TaskItem>` 存储待执行任务，按执行时间排序
2. **工作线程**：延迟创建，守护线程，循环从队列获取任务执行
3. **状态管理**：`INIT → BUSY → IDLE → DORMANT → DESTROY`

关键执行逻辑 (`DispatcherQueue:208-237`):
```java
protected void handleTask(Task task) {
    if(!isCoroutine || task instanceof IDLETask) {
        task.run(); // 标准队列直接执行
    } else {
        coroutinePool.submit(task); // IO队列提交到线程池
    }
}
```

### 线程安全策略

1. **对象锁保护共享状态**：
   - `statusLock`: 保护队列状态
   - `taskQueueLock`: 保护任务队列
   - `threadLock`: 保护工作线程引用

2. **同步集合**：
   - `Collections.synchronizedMap` 用于 SimpleKV 的 kvMap (`SimpleKV:30`)
   - `Collections.synchronizedSet` 用于 pendingRemoveKey (`SimpleKV:31`)

3. **wait/notify 机制**：任务队列空时工作线程等待 (`DispatcherQueue:356-383`)

### 任务调度流程

**TaskItem** (`com.cxuy.framework.coroutine.task.TaskItem:10-87`) 封装任务元数据：
- `runMills`: 计划执行时间戳
- `delay`: 延迟时间
- `task`: 实际任务（实现 Task 接口）
- `id`: 唯一标识，用于优先级排序

优先级比较 (`TaskItem:55-65`):
```java
public int compareTo(TaskItem o) {
    int diff = taskLevel() - o.taskLevel(); // IDLE任务优先级更低
    if(diff != 0) return diff;
    // 同级按执行时间排序
    return Long.compare(runMills, o.runMills);
}
```

**DispatchGroup** (`com.cxuy.framework.coroutine.DispatchGroup:18-164`) 提供任务组管理：
1. **BUILDING 阶段**：通过 `async()` 添加任务到 Transaction.Builder
2. **COMMITTED 阶段**：调用 `notify()` 提交事务，开始并行执行
3. **DONE 阶段**：所有任务完成，执行通知任务

使用 Semaphore 等待全部任务完成 (`DispatchGroup:80-91`):
```java
new Thread(() -> {
    semaphore.acquire(tasks.size()); // 等待所有任务完成
    newTransaction.notifyQueue.async(newTransaction.notifyTask);
    status = Status.DONE;
}).start();
```

## 约束与注意事项

1. **禁止阻塞 IO 线程**：协程调度器在 IO 线程不执行阻塞操作，需提交到 coroutinePool（`DispatcherQueue:212`）
2. **任务队列线程安全**：所有任务操作需加 `taskQueueLock` 保护（`DispatcherQueue:122-135`）
3. **DispatchGroup 状态机**：必须按 BUILDING → COMMITTED → DONE 顺序转换，乱序会抛异常（`DispatchGroup:102-119`）
4. **自动离开机制**：DispatchGroup 默认 autoLeave=true，手动模式需显式调用 `leave()`
5. **工作线程生命周期**：队列 DORMANT 状态超过阈值会触发线程销毁（`DispatcherQueue:295-309`）
6. **IDLETask 复用**：实现 `reuse()` 返回 true 可自动重新入队（`DispatcherQueue:214-219`）
