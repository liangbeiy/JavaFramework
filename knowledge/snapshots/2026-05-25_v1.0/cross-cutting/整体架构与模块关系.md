## 概述

JavaFramework 是一个模块化 Java 脚手架项目，提供事件驱动、协程调度、IO 封装等基础能力。项目采用扁平化包结构，核心框架代码位于 `com.cxuy.framework` 下，上层业务模块包括 `com.cxuy.http`（HTTP 客户端）、`com.cxuy.handler`（请求处理器）。

系统采用事件驱动架构，EventBus 作为核心通信枢纽，支持进程内（`LocalEventBus`）和跨进程（`InterProcessEventBus`）两种通信模式。协程框架（coroutine）提供异步任务调度能力，IO 模块封装 KV 存储和文件操作，为业务逻辑提供统一的数据访问接口。

## 核心机制

### 模块依赖关系

```
com.cxuy.framework (基础框架)
├── eventbus (事件总线)
│   ├── LocalEventBus (进程内通信)
│   └── InterProcessEventBus (跨进程通信，依赖 coroutine)
├── coroutine (协程调度)
│   ├── DispatchQueue (调度接口)
│   ├── DispatchGroup (任务组)
│   └── task (Task, TaskItem)
├── io (IO 操作)
│   ├── kv (KV 存储: SimpleKV, KVMap, MapStorage)
│   └── file (文件操作: FileManager, FileProvider)
├── context (上下文: FrameworkContext, Context)
└── util (工具类: CachePool, JsonUtil, Logger)

上层模块:
├── com.cxuy.http (HTTP 客户端，依赖 framework)
├── com.cxuy.handler (处理器，依赖 framework.eventbus)
└── com.cxuy.server (服务器组件)
```

## 约束与注意事项

1. **框架模块不被反向依赖**：framework 是基础模块，handler/http/server 应仅依赖 framework，不可反向依赖
2. **事件订阅方法规范**：使用 `@Subscribe` 注解标记的方法必须只有一个参数（`LocalEventBus:107`）
3. **跨进程通信限制**：InterProcessEventBus 使用 localhost TCP 连接，仅支持单机跨进程通信
4. **协程 IO 约束**：协程调度器禁止在 IO 线程执行阻塞操作（`DispatcherQueue:212-237`）
5. **文件操作事务性**：FileManager 使用 FileExecutor 保证文件操作的互斥性和共享性（`FileManager:70-93`）
6. **KV 存储初始化**：SimpleKV 构造函数会触发异步文件读取，需等待初始化完成（`SimpleKV:334-346`）
